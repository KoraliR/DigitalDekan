# Аккаунты демонстрационной базы «Цифровой деканат»

Справочник собран скриптом `scripts/export-accounts.mjs` из текущего состояния базы.
Он предназначен для проверки демо-стенда: для реальной эксплуатации нужны собственные пароли
и раздельные роли с ограниченными правами.

## Как войти

- **Студенты:** `/login` — логины `student`, `student2`, `student3`, …
- **Сотрудники:** `/staff-login` — логины `office`, `office2`, `office3`, …
- **Единый демо-пароль:** `dekanat-2026` (задаётся переменной окружения `DEMO_ACCOUNT_PASSWORD`, по умолчанию `dekanat-2026`).
- **Двухшаговый вход.** Сначала введите логин и пароль. После успешной проверки пароля
  приложение показывает на экране шестизначный код подтверждения и создаёт короткоживущую
  сессию входа. Введите код на втором шаге; код действует **5 минут**, после истечения
  вход нужно начать заново. Это демонстрационный режим (`DEMO_2FA_ENABLED=true`),
  а не настоящее SMS/почтовое подтверждение.

> **Важно про пароль.** В базе данных пароль хранится **только в виде bcrypt-хеша** —
> исходное значение прочитать из БД нельзя, поэтому в этой таблице указан общий
> демонстрационный пароль. Студент может сменить пароль сам в разделе «Профиль»;
> у сотрудников страницы профиля нет — пароль меняется из терминала:
> `npm run db:password -- <login>` (на сервере — `docker compose ... exec -it app npm run db:password -- office`).
> Для реальной эксплуатации обязательно задайте свои пароли для каждого аккаунта,
> включите настоящий второй фактор и не публикуйте файлы с паролями в открытом доступе.

## Подсказки для проверки

- `student` — староста группы ИВТ-21-1: у него доступен журнал посещаемости (`/attendance`),
  а в личном кабинете есть заявки, дедлайны, низкие баллы и запись на пересдачу.
- `office` — Мария Орлова, закреплена за всеми группами; `office7` — Ольга Никитина,
  закреплена только за группой ИБ-20-1 (удобно проверять ограничение видимости).
- Все студенты имеют электронный пропуск, выданные книги и объявления на доске кампуса.
- Часть заявок в статусах «Новая»/«В работе» имеет истёкший срок готовности —
  такие заявки показываются сотруднику как просроченные.
